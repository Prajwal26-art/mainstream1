what is SQL
SQL Structured Query Language - It is a language used to store, retrieve, manage and manipulate data in databases.
Main SQL commands - SELECT - Retrieve data, INSERT - Add data, UPDATE - Modify Data, DELETE - Remove data, CREATE - Create database/table, ALTER - Modify table structure, DROP - Delete table/database

SQL:- It is commonly used with databases such as MySQL, PostgreSQL, Oracle, Microsoft SQL Server, and SQLite.

Application:- It is the solution for human day-to-day life challenges, or a software program designed to help users perform a specific task on a computer, mobile, or us
For Ex- WhatsApp for messaging, Google Chrome for browsing, MS Word for writing documents.

It types are :-
1) Desktop Application- Software that runs on a computer/laptop. Ex- MS Word, VLC Media Player, Photoshop.
2) Mobile Application - Which executes on Mobile phones, ex- WhatsApp, Instagram, YouTube.
3) Web Application - Which is execute with the help of internet on web-browser anytime, anywhere on from any device, ex- Gmail, Google Docs, Online Banking, etc.
4) Enterprise Application - It is used for created a particular organisation, such as Banking or finance institutes.
5) Embedded Application - It is consist of Hardware and Software is known as Embedded Application, ex- Alexa, Robot, Microwave, etc.

Programming Language :- It is an language where we human can give instructions to a computer and tell  it what to do, or is a way to communicate with a computer or machine and create software/applications.

It has two types :-
I] High-Level Programming Language :- It is easy to understand, learn, read and write for Humans; it is machine-independent it's ex's are Python, Java, PHP, etc.
II] Low-Level Programming Language :- It is closer to the computer's hardware and difficult for humans to understand; it is also difficult to write and learn, and it is machine-dependent language, it's ex's are C, C++, Assembly and Machine language, etc.

#syntax=select *from tablename limit value;
